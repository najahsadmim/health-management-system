# BRAC University CSE370 — Database Systems
---------------------------------

## Healthcare Service Website

A healthcare service website developed as a database systems project for **CSE370 at BRAC University (BRACU)**. The application aims to bring common healthcare services together in one platform, allowing users to find doctors, search for diseases and symptoms, compare medicine prices, and access healthcare-related services such as caregivers, nurses, attendants, and ambulances.

The system uses **PHP and MySQL** for the backend and database, with **HTML, CSS, and JavaScript** for the frontend.

## Core Features

* User registration, login, logout, and role-based access
* Disease and symptom search
* Doctor search and profiles
* Doctor appointment booking
* Medicine search and price comparison
* Online medicine purchase links
* Caregiver, nurse, and attendant services
* Ambulance services
* Admin dashboard and management functions
* Doctor, medicine, seller, caregiver, ambulance, and nurse/attendant management
* Search and filtering
* Responsive web design
* MySQL database integration

## Technology Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Development Environment:** XAMPP / Apache / phpMyAdmin

The basic application flow is:

**User → Website → PHP → MySQL Database → Result**

## Project Objective

The goal of the project is to design and implement a relational healthcare service system that keeps different types of healthcare information in separate, connected database tables. This allows users to search and access healthcare services while demonstrating practical concepts of **database design, relationships, SQL queries, PHP backend development, and web application development**.
